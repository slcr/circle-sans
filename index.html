What changed04
Q

A new tail

The centred vertical bar read as the Quake logo. It is now a diagonal stroke crossing the bowl, held at a fixed −52° so the angle never drifts with weight.

g

Long stem by default

Previously tucked away in ss02. The accented forms — ğ ĝ ġ ģ — follow automatically.

&

Open ampersand

The “et” form, previously ss04, is now the default and keeps its own width and kerning.

1234

Figures left alone

Proportional, as drawn. Tabular was tried as a default and reverted — it goes gappy in running text. Switch it on per component instead.
